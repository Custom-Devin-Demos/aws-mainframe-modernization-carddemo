# sample-data

The shipped `app/data/ASCII/{tcatbal,discgrp,acctdata,cardxref}.txt`, normalised by
`tools/build_fixture_inputs.py` (CRLF -> LF, records padded to 50/50/300/50 bytes, sorted by
primary key to emulate KSDS order). No values were changed.

Characteristics of the shipped data (see `../README.md` for layouts):

* 50 TCATBAL records, one per account 1..50, all type `01` category `0001`, **all balances +0.00**.
* All 50 accounts have a blank `ACCT-GROUP-ID` -> DISCGRP status 23 -> `DEFAULT` group
  (`01`/`0001` = 15.00%) for every record; `run.log` therefore contains 50 pairs of
  `DISCLOSURE GROUP RECORD MISSING` / `TRY WITH DEFAULT GROUP CODE`.

Expected output (generated by `tools/generate.sh sample-data`, PARM-DATE `2022071800`):

* `expected/systran.txt`: 50 transactions, TRAN-ID `2022071800000001`..`2022071800000050`,
  TRAN-AMT +0.00 each, TRAN-CARD-NUM = the account's card from cardxref.
* `expected/acctdata.txt`: identical to `input/acctdata.txt` (interest 0.00 everywhere; account 50
  is the unposted last account anyway).
* Bytes 279-330 of `systran.txt` are run-time timestamps and must be masked when comparing.
